# Using LLMs in R with ellmer

## LatinR 2026 Conference Workshop by Nic Crane

**This repository is a work in progress and does not currently reflect the final materials**


### Workshop Overview

The {ellmer} package allows you to work directly with LLMs in R. 

In this hands-on workshop, you'll learn how to use LLMs programmatically with {ellmer}, to extract data from unstructured text and create tools to help chatbots work with functions as directly from an R session.

**What you'll learn:**

- Getting started with LLMs in R using {ellmer}
- Prompt engineering for more predictable results
- Extracting structured data from unstructured text
- Using LLMs to call R functions (tool calling)
